模拟栈实现组合型枚举 —— 交互式讲解

题源:《算法竞赛进阶指南》(AcWing 93 风格) · 演示参数 n=4, m=2 · 共 6 个组合

一、这个程序要干什么

从 1..n 里选 m 个数,输出所有组合。n=4, m=2 时输出 6 个: 3 4 / 2 4 / 2 3 / 1 4 / 1 3 / 1 2(顺序由下面代码的"先不选后选"搜索决定)。

核心思想:递归版 calc(x) 的每一次函数调用,都要系统帮它做三件事: ① 存参数 ② 记返回到哪 ③ 保存现场。这段代码不用系统栈,而是用一个 stack[] 数组和 address 变量,把这三件事手动做出来。

全局变量

vector<int> chosen当前路径已选的数(一个组合的"半成品")
int stack[100010]手工"调用栈"。每个函数调用占 3 个槽:x 参数 / 返回地址 / 旧 top
int top栈顶指针(已用的槽数)
int address程序计数器:当前函数执行到哪一步,取值只有 0 / 1 / 2
int n, m输入:从 n 个数里选 m 个

二、逐函数讲解

① call(x, ret_addr) —— 模拟"调用一个函数 calc(x)"

void call(int x, int ret_addr) {
    int old_top = top;        // 先记住"我现在栈顶在哪"
    stack[++top] = x;         // 槽1:新一层的参数 x
    stack[++top] = ret_addr;  // 槽2:返回地址(这层结束回到调用者时,address 该变成几)
    stack[++top] = old_top;   // 槽3:旧 top(返程时靠它把整个帧弹掉)
}

压入的 3 个槽 = 一个函数帧。例:call(2, 1) 表示"进入 calc(2),等它结束我就从 case 1 接着干",压出 (2, 1, 旧top)。

② ret() —— 模拟"函数 return"

int ret() {
    int ret_addr = stack[top - 1];  // 取我这个帧第 2 槽:返回地址
    top = stack[top];               // 取第 3 槽:旧 top,整个帧被弹掉
    return ret_addr;                // 告诉调用者:回去后该从 case 几继续
}

所以栈顶 3 槽的语义永远是:stack[top-2]=当前参数,stack[top-1]=返回地址, stack[top]=旧 top。记住这句,整个循环全靠它。

③ main —— 入口 + 调度器

cin >> n >> m;
call(1, 0);          // 手动发起第一次调用:进入 calc(1);返回地址 0(=回到 main,栈空即结束)
while (top) {        // 调度器:栈不空 = 还有没结束的函数
    int x = stack[top - 2];   // 取栈顶帧参数 = 现在执行到 calc(x)
    switch (address) { ... }  // 按程序计数器分发到 case 0 / 1 / 2
}

原来递归时由 CPU 自动完成的"取当前参数 + 决定执行到哪",这里变成 while 循环里显式的三行。

④ case 0 —— "函数开头":剪枝 → 出口 → 不选分支

case 0:
    if (chosen.size()>m || chosen.size()+(n-x+1); puts("");
        address = ret(); continue;      // 输出完 return
    }
    call(x+1, 1);                       // 不选 x,进入下一层;该层结束时回到 case 1
    address = 0;  continue;             // ★ 新压入的帧永远从 case 0 开始干活
}

两个 return 点、一个递归点。剪枝条件:chosen.size()>m 选超了; chosen.size()+(n-x+1)<m 剩下的数全选也凑不够 m 个。例(x=4,已选 0 个):0+(4-4+1)=1 < 2 → 剪!

最精妙的一行:address = 0; continue;。真递归里子函数结束会自动回到调用处;这里必须手动把 address 归 0,让 while 重新取栈顶(新帧)的参数。

⑤ case 1 —— "从不选分支回来了":选 x,再往下

case 1:
    chosen.push_back(x);   // 执行"这一步该选 x"的动作
    call(x+1, 2);          // 选完继续下一层;该层结束时回到 case 2
    address = 0;  continue;
}

⑥ case 2 —— "从选分支回来了"(或本层干完):撤销并返回

case 2:
    chosen.pop_back();     // 撤销刚才选的 x(回溯)
    address = ret();       // 本层彻底结束,接管调用者存的返回地址(0/1/2 都可能!)
}

注意 case 2 不写 continue:switch 后面就是 while 循环体末尾,自然回到 while 开头。而 address = ret() 的返回值由调用者决定——被 case0 调进来→回 1;被 case1 调进来→回 2; 被 main 调进来→回 0(栈空,整个程序结束)。

⑦ 递归 ↔ 模拟栈 对照表(理解后这张表就够了)

递归 calc(x) 里的动作模拟栈版本
函数入口case 0
开头的剪枝 returncase 0: address=ret(); continue;
x==n+1 输出后 returncase 0: 输出后 address=ret(); continue;
calc(x+1) —— 不选分支case 0: call(x+1, 1); address=0;
push_back(x) —— 选 xcase 1
calc(x+1) —— 选完再往后case 1: call(x+1, 2); address=0;
pop_back() 后 returncase 2: pop_back(); address=ret();

一句话总结:3 个 return/递归点正好对应 3 个 case,address 只可能是 0/1/2; 每一个"函数调用"= 栈里 3 个槽;整个 while 循环就是把"递归调度"摊平。
